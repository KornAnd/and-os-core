# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 9.5.x   | :white_check_mark: |
| < 9.5   | :x:                |

## Reporting a Vulnerability

Security and data isolation are core engineering tenets of AnD os.

If you discover a security vulnerability or data isolation bypass in AnD os:
1. Please **do not** report it in public GitHub issues.
2. Email details to the repository maintainer via GitHub profile contact.
3. Include reproduction steps, environment details, and sample inputs.

We will acknowledge reports within 48 hours and work with you on a coordinated disclosure timeline.
