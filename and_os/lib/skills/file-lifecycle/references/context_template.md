# Шаблон CONTEXT.md для новых каталогов

Используется скиллом `sync-context` при создании нового каталога.

```markdown
---
tags:
 - <category>
 - контекст
color: var(--mk-color-<color>)
---

# Контекст каталога: <name>/

**Назначение:** <одна строка>

**Хештеги:** #<tag1> #<tag2>

---

## Файлы

### `[[<path>/<file>|<file>.md]]` — <описание>

## Подкаталоги

### <subdir>/ — <описание>

---

## Связи

- `[[<path>]]` — <почему>

---

*Обновлено: ДД.ММ.ГГГГ*
```
